每天怎么把项目跑起来

Docker 起中间件 → IDEA 起三个后端 → npm 起前端 → 浏览器 3000。

每日启动五步（PowerShell + IDEA 交替）

  1. Docker Desktop开始菜单打开，等右下角鲸鱼图标变绿（约 30 秒）。
  2. 起中间件（9 个容器） 
    cd G:\kuros-web
docker compose up -d
docker compose ps    # 等全部 healthy，约 30 秒
  3. IDEA 起三个后端（按序，一个等健康再点下一个） 运行配置下拉框（仓库 .run/ 已内置）：backend :8090 → user :8091 → gateway :8080。 控制台出现 "Started ...Application in X seconds" 即成功。顺序原因：gateway 靠 Nacos 找到前两个才能转发。
  4. 起前端 
    cd G:\kuros-web\front
npm run dev
  5. 浏览器验证打开 localhost:3000，用下方账号登录。

停止与排障

  • 停前端：终端 Ctrl+C；停后端：IDEA 红色方块；停中间件：docker compose down（数据保留在卷里，下次 up 接着用）
  • 某个容器卡 starting：docker compose logs -f 名字
  • 后端起不来：看 IDEA 控制台最后 30 行；常见是 Docker 中间件还没 healthy 就点了启动
  • 内存红线：三个后端必须一个一个启动（.run/ 配置已限堆），不要同时点
  • 全家桶演示模式（与开发模式二选一）：docker compose --profile full up -d --build
