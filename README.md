# 鸣潮玩家攻略与内容社区

这是项目工作区，当前已包含 Next.js 前端 Demo，后续计划加入 Java 后端。

## 目录

- `front/`：Next.js + TypeScript 前端
- `docs/`：产品计划、前端 Demo 计划和人为准备事项
- `backend/`：预留给 Java 后端

## 启动前端

```powershell
cd .\front
npm install
npm run dev
```

访问 http://localhost:3000。

## 检查前端

```powershell
cd .\front
npm run lint
npm run build
```
