# 社区核心页面 UI 体验重构规格

## 状态

- 设计方向：已确认
- 参考产品：库街区鸣潮社区，仅参考信息架构、密度和交互节奏
- 产品品牌与内容：使用本项目自己的鸣潮社区标识、文案、素材和数据
- 实施方式：按垂直切片逐页交付，保持现有 REST API 与用户行为不变

## 目标

把当前偏通用模板化的界面重构为更接近成熟游戏社区的阅读与创作体验：层级清楚、内容优先、桌面端紧凑但不拥挤、移动端无横向滚动。重构覆盖首页、帖子详情、个人中心和发布编辑器，并把共同的顶部导航、侧栏、按钮、表单、列表和响应式规则同步到二级页面。

## 非目标

- 不复制库街区 Logo、二维码、吉祥物、宣传素材或精确像素
- 不改变现有登录、帖子、评论、点赞、收藏、关注、举报、上传接口
- 不在本轮引入新的后端可见性、富文本存储或草稿表
- 不新增没有真实行为的按钮
- 不把所有二级业务页重新设计为全新信息架构

## 视觉系统

### 色彩

- 页面背景：`#f3f5f8`
- 主表面：`#ffffff`
- 顶栏：`#17191d`
- 主文本：`#17202b`
- 次级文本：`#6f7e90`
- 弱文本：`#9aa8b8`
- 分割线：`#e7ebf0`
- 主操作：`#14cbd3`
- 主操作浅底：`#e8fafb`
- 危险操作：`#e45b65`

### 形态

- 常规圆角仅使用 2、4、6、8px；头像和状态点除外
- 卡片主要依赖白色表面与分割线，不依赖大阴影
- 阴影只用于下拉菜单、模态框和悬浮操作层
- 标签采用轻底色、小圆角和正常字重，不使用大号胶囊
- 图标统一使用 Lucide 线性图标，常规 16–20px，`strokeWidth` 1.7–1.9

### 字体与密度

- 顶部导航：14px / 500–600
- 页面标题：28–34px / 600–700
- 列表标题：17–20px / 600–700
- 正文：14–16px；帖子正文行高 1.85–1.95
- 元信息：12px / 400–500
- 桌面内容最大宽度：1360px，左右安全边距至少 24px

## 页面规格

### 首页

- 64px 黑色顶栏，保留社区导航、搜索、发布、登录/个人中心
- 三栏结构：220px 频道栏、弹性内容流、320px 推荐与工具栏
- 横幅高度控制在约 220px，首屏必须露出至少一篇完整帖子主体
- 帖子内容按作者、标题、摘要、可选媒体、标签、互动顺序排列
- 图片不是每篇必需；没有图片时不保留空媒体位
- 右栏工具采用紧凑图标网格，推荐列表按信息行展示

### 帖子详情

- 左侧互动栏在桌面端固定于视口可用区域
- 正文主列约 820px；右侧作者、目录和话题栏约 290px，并保持 sticky
- 正文使用低装饰阅读表面，减少头部空白和嵌套卡片
- 评论区与文章属于同一阅读主列，包含评论筛选、排序、编辑器、一级回复和已有操作
- 移动端隐藏独立左右栏，把互动操作收进正文底部或浮动操作条

### 个人中心

- 资料概览横向展示头像、身份、统计、简介和游戏数据卡
- 下方为约 250px 导航与弹性内容列表
- 帖子、评论、收藏、关注、粉丝继续连接现有接口
- 编辑和删除操作保持可见但弱化，不与标题争夺注意力
- 未登录态保持简洁，不渲染完整资料骨架

### 发布编辑器

- 使用聚焦式编辑器，不再使用“页面标题卡 + 双栏后台表单”结构
- 顶部工具栏操作 Markdown：标题、粗体、斜体、引用、列表、链接和图片
- 标题、正文、类型、标签继续沿用现有校验与发布接口
- 图片按钮调用现有上传流程并插入 Markdown
- 草稿保存到带版本号的 `localStorage`，进入页面可恢复、发布成功后清理
- 底部操作栏展示字数、草稿和发布；不提供没有后端支持的可见性切换

## 响应式边界

- `>= 1280px`：完整三栏/双侧栏布局
- `960–1279px`：隐藏首页右栏，频道栏保留；详情页隐藏右栏目录
- `720–959px`：顶部导航收缩，频道改抽屉，内容单列
- `< 720px`：16px 页面边距，卡片圆角归零或 4px，表单和列表单列
- 所有验收宽度不得出现页面级横向滚动：1440、1280、1024、768、390px

## 可访问性与交互

- 所有图标按钮必须有可访问名称
- 键盘可打开和关闭下拉菜单、登录弹窗及发布工具栏操作
- 聚焦态必须清晰可见，颜色不能只靠浅灰差异表达
- 动画只用于菜单、悬浮反馈和状态过渡，并尊重 `prefers-reduced-motion`
- 加载、空状态、错误状态继续显示可理解文案

## 测试接缝

以下是本轮 TDD 的公共行为边界，等待实现前确认：

1. 路由页面接缝：首页、帖子详情、个人中心、发布页可以渲染关键区域，且没有因视觉重构丢失可访问名称。
2. 发布编辑器接缝：格式化操作修改选区、草稿保存/恢复、图片插入和提交继续通过公开 UI 行为验证。
3. 浏览器接缝：1440、1024、390px 不出现页面级横向滚动；关键桌面侧栏 sticky，移动端按规格折叠。
4. 回归接缝：登录、帖子新标签页、评论、点赞/收藏/关注、编辑/删除仍通过现有公开页面入口完成。

## 验收标准

- 四个核心页面与已批准概念在布局、密度、色彩、字体、圆角和内容层级上保持一致
- 首页首屏内容密度明显改善，1024px 横向滚动缺陷消失
- 发布页不含空工具按钮，草稿和 Markdown 工具栏可实际使用
- 登录、互动、评论、发布、个人中心接口行为不回退
- `npm run lint` 和 `npm run build` 通过
- 使用真实浏览器完成 1440、1024、390px 截图对照和核心交互验证
