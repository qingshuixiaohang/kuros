# 社区多图帖子与首页 3D Banner 轮播规格

关联 Issue：[#50](https://github.com/qingshuixiaohang/kuros/issues/50)

## 目标

让帖子中的多张图片可被完整浏览，并将首页固定 Banner 改为具有库街区风格的层叠轮播，同时保持当前鸣潮社区的桌面端布局和移动端可用性。

## 交互规格

### 帖子卡片

- `mediaUrls` 为空时继续使用现有无图状态。
- 单图保持当前单图卡片样式。
- 多图改为单张主图轮播，显示左右箭头和当前位置圆点。
- 默认不自动播放，避免用户滚动信息流时内容自行跳动。
- 图片点击继续新开对应帖子详情页。

### 帖子详情

- `mediaUrls` 中的全部图片都可以查看。
- 支持左右箭头、圆点、键盘 `ArrowLeft`/`ArrowRight`。
- 桌面端支持鼠标拖动，移动端支持触摸滑动。
- 轮播切换不影响正文、评论区和右侧固定栏。
- 只有一张图片时隐藏切换控件。

### 首页 Banner

- 桌面端显示中心卡片和左右预览卡片。
- 中心卡片使用较大尺寸；相邻卡片使用缩放、透明度、横向位移和 `rotateY` 形成轻量景深。
- 每 5 秒自动切换；鼠标悬停、键盘聚焦或用户手动操作时暂停自动切换。
- 支持左右箭头、圆点和键盘切换。
- 移动端只保留中心图片、圆点和滑动，关闭侧边 3D 预览。

## 技术约束

- 使用 React 状态和 CSS `perspective`/`transform` 实现，不引入 WebGL 或第三方轮播依赖。
- 复用现有本地 `/art` 资源和 `Guide.mediaUrls` 数据结构。
- 图片使用 Next.js `Image`，保持固定容器比例，避免布局跳动。
- 轮播控件使用语义化按钮、可见焦点和 `aria-label`。
- 尊重 `prefers-reduced-motion`：减少或关闭自动过渡。

## 验收

1. 首页 Banner 可自动和手动切换，桌面端有层叠景深效果。
2. 首页多图帖子可逐张查看。
3. 详情页可查看全部图片，并支持键盘和触摸/拖动。
4. 移动端无横向溢出或遮挡。
5. `npm run lint`、`npm run build` 和现有 Playwright E2E 通过。
