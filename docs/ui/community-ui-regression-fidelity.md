### 2026-10-05 第三轮：字号/留白按库街区实测值修正 + 消息铃铛

### 2026-10-05 第四轮：全页字号分布统一（根因：140 处微字）

### 2026-10-05 第五轮：侧栏对齐实测零折中（18px/500）

用户指出侧栏文字仍偏小。复测库街区侧栏：文字 **18px/500/#aeb6c2**、图标 24px、行高约 52px——第四轮我取了"视觉平衡"的 16px，是对实测值的折中，导致体感仍小。本轮零折中：
- `.channel-item` 生效规则（第二处后置覆盖）→ 18px/500、#aeb6c2、min-height 52px
- 侧栏图标 16 → 22px（描边图标对 24px 实测的视觉等重）
- 复测确认 getComputedStyle：18px/500 #aeb6c2 ✓

教训记录：凡实测得到的值，不要再做"我觉得"的折中——体感差异正是折中的那 2px。

### 2026-10-05 第六轮：右栏资讯列表对齐（序号榜 → 分类标签）

用户指出右栏与库街区不同。库街区右栏为分类 chip（置顶/资讯）+ 标题省略号，无数字序号、无热度标；本站为 1/2/3 彩色序号 + 红“热”标。

- `.rank`/`.rank-1~3` 序号样式 → `.news-chip` 三态分类标签：官方公告→“官方”（石板蓝灰）、版本前瞻→“资讯”（青）、活动资讯→“活动”（琥珀），样式对齐库街区 chip 配色逻辑
- 删除 `.ranking-item b` 热标样式与 JSX
- 标题省略号本就有（nowrap+ellipsis）保留
- e2e 40/40 相关套件绿，全套 70/70 绿

### 2026-10-05 第七~八轮：全页长图系统对比（多图宫格 + 详情页对齐）
