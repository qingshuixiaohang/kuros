## Fidelity ledger

| 视觉关系 | 设计基准 | 当前实现与验证 |
| --- | --- | --- |
| 顶部导航 | 深色 64px 导航、青色当前频道、紧凑搜索与发布入口 | 首页、帖子详情、个人中心和发布页共用 `TopNavigation`；1440px 截图确认层级一致，键盘测试覆盖“更多”菜单。 |
| 首页信息密度 | 左侧频道、中央内容流、右侧推荐/工具三栏 | 1440px 保留三栏；1024px 收起推荐栏；1280px 保持内容区可读；核心路由无页面级横向滚动。 |
| 帖子详情阅读辅助 | 左侧互动栏、中央正文、右侧作者/目录上下文 | 1440px 验证两侧 sticky；1024px 隐藏右侧上下文但保留互动栏；Markdown 标题目录只在存在标题时生成。 |
| 个人中心层级 | 横向资料概览、左侧分区导航、右侧帖子内容 | 1440px 使用资料 Hero + 分区导航 + 内容列表；1024px/768px 做断点回归；公开 URL 分区切换保持可用。 |
| 发布编辑器 | 聚焦正文工作区、工具栏、底部固定操作栏 | 1440px 与 1280px 保留宽编辑区；1024px/768px/390px 无横向滚动；帖子设置滚动遵守 reduced-motion。 |
| 视觉语言 | 白色内容面、深色文字、鸣潮青色强调、克制边框和小圆角 | 使用项目自有鸣潮素材与品牌文案；未引入库街区 Logo 或外部产品文案，仅参考信息密度和交互节奏。 |

## 合同边界记录

- 发布编辑器的标题上限保留现有后端契约 `200`，页面字符计数按该契约展示。
- “发布后公开展示”是当前产品规则说明，不新增未定义的可见性切换。
- 本 Issue 只处理 UI、可访问性与浏览器回归，不修改后端、数据库或 REST API。
