## 合同边界记录

- 发布编辑器的标题上限保留现有后端契约 `200`，页面字符计数按该契约展示。
- “发布后公开展示”是当前产品规则说明，不新增未定义的可见性切换。
- 本 Issue 只处理 UI、可访问性与浏览器回归，不修改后端、数据库或 REST API。

## 2026-10-05 库街区实站对比轮次（redesign-existing-projects 方法论）

数据来源：库街区网页版实站截图（`https://www.kurobbs.com/mc/home/9`，公开页面，仅布局参考，未复制素材/代码），与本项目 1440px 首页截图逐项对比。

| 对比项 | 库街区实站 | 本轮修复（6a34430 / 本轮 CSS） |
|---|---|---|
| 侧栏密度 | 紧凑图标列表（13~14px、约 38px 行高、小图标） | 16px/55px/gap16 → 13.5px/38px/gap12，图标 20→16；删除底部 72px 留白装饰块 |
| 帖子卡标题 | 约 16px | 18 → 16px，外边距收紧 |
| 卡片交互 | 有悬停反馈 | 新增 hover 浮起（translateY+淡阴影 200ms） |
| 帖子配图 | 插图式，约卡片六成宽、非通栏 | `.post-cover` 由通栏 232px 高封面 → `width: min(58%, 430px); aspect-ratio: 16/10` 左对齐插图 |
| 话题标签 | 纯灰文字 "#标签" 排列 | 去掉灰底/内边距，改纯文字 12px |
| 关注按钮 | "+关注" 纯青文字 | 去掉青色浅底实心，改纯青文字（hover 下划线），已关注态同步改纯文字 |
| 统计行 | 图标+等宽小数字 | gap 30→22，数字 tabular-nums |
| 帖子链接行为 | 帖子新标签页打开 | 攻略列表/搜索结果补 `target=_blank`（此前仅首页信息流/个人中心/评论区有） |
