# 鸣潮玩家攻略社区：前端 Demo 计划（修订版）

## 目标

先交付一个不依赖 Java 后端、打开浏览器即可演示的鸣潮玩家社区 Demo。整体信息架构参考库街区鸣潮社区：顶部游戏栏、左侧频道、中间内容区、右侧推荐/工具栏。页面先验证社区产品结构、视觉方向和移动端布局，不在第一轮提前实现认证、数据库或上传链路。

## 本轮交付范围

- Next.js App Router + TypeScript + Tailwind CSS 基础工程
- 库街区式浅色三栏桌面社区：首页横幅、频道侧栏、帖子信息流、推荐热榜和工具箱
- 移动端单列社区：顶部操作栏、频道抽屉、帖子流和图鉴卡片
- 本地 Mock 攻略/资讯/工具数据
- 可交互的频道切换、全局搜索、帖子收藏、攻略分类筛选、发布表单 Demo
- 攻略列表、攻略详情、角色图鉴、声骸图鉴、版本资讯、发布页面
- 统一主题 token、可复用组件、空搜索结果状态
- 符合鸣潮冷色科幻氛围的本地 AI 生成角色素材

## 暂不做

- Java API、登录注册、JWT/HttpOnly Cookie
- MySQL、Redis、MinIO、消息队列、搜索服务
- Markdown 编辑器、真实图片上传、草稿持久化和审核
- 管理后台和 Docker/Nginx 部署

## 后续迭代顺序

1. API 契约：和 Java 后端一起确定分页、错误结构、认证传递方式。
2. 接入真实角色/声骸/攻略素材，替换当前 Demo Mock 数据。
3. TanStack Query 接入：先替换首页攻略列表，再接详情和图鉴查询。
4. 登录、点赞、收藏、评论、发布和上传：按一条完整业务链逐步联调。
5. 管理后台、异常状态、Playwright 核心流程和部署。

## Demo 验收标准

- 在 `front/` 目录执行 `npm run dev` 能启动首页，`npm run lint` 和 `npm run build` 通过。
- 1280px 左右视口无横向滚动，黑色顶部栏、左侧频道、中间内容和右侧推荐层级清晰。
- 390px 左右视口变成单列，频道可通过菜单打开，卡片和图鉴保持可读。
- 图片来自本地 `public/art`，加载失败不会让布局塌陷。
- 搜索无结果时显示空状态；收藏后图标立即变化。
- 页面没有把所有内容塞进一个 `page.tsx`。

## 视觉基线

- 浅灰页面背景 `#f3f5f8`，黑色顶部栏，白色内容卡片。
- 鸣潮青 `#14cbd3` 用于选中态、关注、链接和主要操作。
- 参考库街区的社区信息密度、圆角卡片、帖子元信息和左右侧栏，不复制官方 Logo、二维码或代码。
- 当前主视觉：`front/public/art/hero-tide.png`。
- 当前 AI 生成角色素材：`front/public/art/character-tide.png`、`front/public/art/character-rover.png`、`front/public/art/character-lavender.png`。
