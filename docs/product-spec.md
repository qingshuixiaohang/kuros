# 鸣潮玩家攻略与内容社区产品需求

## 1. 产品定位

这是一个面向鸣潮玩家的非官方攻略与内容社区。产品重点是让玩家能够找到可执行的配队、角色培养和探索经验，也能发布内容并参与讨论。视觉上借鉴库街区的内容密度和社区层级，但品牌、素材、文案和实现保持原创。

## 2. 用户角色

| 角色 | 主要能力 |
| --- | --- |
| 游客 | 浏览公开帖子、搜索攻略、查看角色/声骸资料和资讯 |
| 登录用户 | 发布帖子、点赞、收藏、关注作者、发表评论和删除自己的评论 |
| 管理员 | 审核或下架帖子、管理评论、维护角色资料和公告、处理举报、封禁用户 |

## 3. MVP 范围

- 首页推荐、最新和关注信息流
- 攻略列表、分类/标签/关键词筛选、详情页
- 角色和声骸图鉴的基础查询
- 手机号验证码登录、Cookie 会话恢复和退出
- 帖子点赞、收藏、关注作者
- 评论、一级回复、删除自己的评论
- 登录用户发布攻略或普通社区内容
- 图片上传基础链路
- 管理员对帖子和评论进行审核/下架

## 4. 第二阶段

- Markdown 编辑器、草稿保存和编辑帖子
- 角色关联、培养材料和推荐配队数据
- 举报处理工作台、用户封禁记录和操作审计
- 搜索索引、缓存和更细粒度的推荐排序
- 图片压缩、CDN 和内容审核服务

## 5. 暂不实现

即时聊天、支付、游戏账号绑定、复杂推荐算法、地图工具、抽卡模拟和积分商城不进入当前版本。

## 6. 关键业务规则

- 只有登录用户可以创建内容和写入互动数据。
- 帖子作者由服务端当前会话决定，客户端不能通过请求体伪造作者。
- 公开列表和详情只返回 `PUBLISHED` 帖子；删除或下架内容不可被游客访问。
- 点赞、收藏和关注以用户与目标的组合键保证幂等。
- 评论当前支持一级回复；删除评论保留占位，不物理删除展示记录。
- 所有写请求使用 HttpOnly 会话 Cookie，并通过 CSRF Token 防护。
